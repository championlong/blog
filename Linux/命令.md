# journalctl
查看Linux上Systemd的日志
1. 查看所有日志：journalctl
2. 按服务名称过滤：journalctl -u [service-name]
3. 按时间范围过滤：journalctl --since "YYYY-MM-DD HH:MM:SS" --until "YYYY-MM-DD HH:MM:SS"
4. 按日志优先级过滤：journalctl -p [priority-level]
5. 实时查看日志：journalctl -f
6. 关键字查询：journalctl -k [keyword]

*# 查看服务全部日志*

journalctl -u ads-ai-agent

*# 实时跟踪（等同 tail -f）*

journalctl -u ads-ai-agent -f

*# 最近 100 行*

journalctl -u ads-ai-agent -n 100

*# 最近 30 分钟*

journalctl -u ads-ai-agent --since "30 min ago"

*# 指定时间范围*

journalctl -u ads-ai-agent --since "2026-04-09 10:00" --until "2026-04-09 12:00"

*# 只看错误级别*

journalctl -u ads-ai-agent -p err

*# 本次启动以来的日志*

journalctl -u ads-ai-agent -b
